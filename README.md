# Site pessoal — João Marcos Pontes

Cartão de visita profissional em formato de site: apresentação, experiência e formação em engenharia de produção.

**Online em [joaopontes.netlify.app](https://joaopontes.netlify.app)**

## Sobre

Engenheiro de produção recém-formado, atuando em suprimentos: cadeia de compras, controle de estoque, análise de custos e automação de rotinas de análise. O site reúne esse histórico em uma página só, pensada para leitura rápida.

## Construção

- HTML e CSS, sem framework
- Layout responsivo
- Identidade visual própria: grafite e laranja de segurança, referência à sinalização industrial
- Publicado via Netlify
